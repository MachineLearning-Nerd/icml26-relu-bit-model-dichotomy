# Author thank-you note

This repository is an independent reproduction and audit of:

**Why ReLU? A Bit-Model Dichotomy for Deep Network Training**
Ilan Doron-Arad and Elchanan Mossel
[arXiv:2602.19017](https://arxiv.org/abs/2602.19017) · [OpenReview nMS1YTjHMH](https://openreview.net/forum?id=nMS1YTjHMH)

Thank you to Ilan Doron-Arad and Elchanan Mossel for presenting the bit-model
complexity dichotomy clearly and for publishing the source record behind the
results. The explicit straight-line-program identity and theorem structure make
it possible to audit a local gadget independently while keeping the stronger
complexity claims clearly marked as work still to be reproduced.

This dossier is a transparent companion record. It separates exact finite
arithmetic evidence from theorem-level reductions and does not imply author
review, endorsement, or responsibility for this independent implementation.
